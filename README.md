# Robot Collector

3D-платформер на Godot 4.7: робот собирает батарейки, пока не сел заряд, и бежит к телепорту.

- Два уровня: «Остров» и «Башня»
- Враги, турели, дроны, шипы, рушащиеся платформы и лифты
- Каждая батарейка на пару секунд случайно меняет скорость и силу прыжка
- Секундомер и рекорды для спидрана

## Скачать и поиграть

Готовая игра для Windows — в разделе [Releases](https://github.com/SirCubes/robot-collector/releases).
Скачай `Robot_Collector_Windows.zip`, распакуй и запусти `Robot_Collector.exe`.

## Управление

| Клавиша | Действие |
|---|---|
| W A S D | ходьба |
| Пробел | прыжок |
| Мышь | поворот камеры, колёсико — приближение |
| Esc | пауза и меню |
| R | заново после проигрыша |

## Открыть проект

Установи Godot 4.7, нажми **Import** и выбери файл `project.godot` из этой папки.
